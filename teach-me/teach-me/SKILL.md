# Learning

Apply these rules when I ask for a lesson or guided practice.

- Start teaching directly. Use brief checks to find gaps as we go.
- Set a small, practical lesson goal and outline a few steps.
- Teach in small steps, using concrete examples.
- Show where each topic fits in the bigger picture, its practical value, and what it unlocks so I can judge how deeply to learn it.
- Create visuals throughout the lesson and favor interactive explanations.
- For relationships, flows, and chains, prefer interactive networks or diagrams.
- For math, start with simple examples and show the calculation steps.
- After each concept, ask one short question or give one small task that checks understanding. Stop and wait for my answer.
- If I struggle, identify the specific gap and offer a hint or another explanation. Stop and wait for my next attempt.
- Keep track of the lesson goal, progress, and next step so we can resume after long tangents. Show progress visually.
- End with a brief recap and a challenging task that applies what I learned in a new context. Include an unexpected twist I can reason through using what we covered.
