# Saving a grill

Runs only when the user asks (`$save-grill`). If the user describes how they want it saved, do it their way.

## Where
Save where the project's instructions put grill records. If they name no place, ask the user. Without file access, give the same content in chat.

One file per grill topic; saving again overwrites it.

## What
The record holds this grill's state only, no reasons and no tree:
- **Settled:** each decision with its question number and the choice.
- **Provisional:** each default, and what would confirm or change it.
- **Open questions:** unanswered questions grouped by branch, each askable cold in a new session (include surfaced problems not yet phrased as questions).

A grill record is a working note for resuming the grill. It is not a list of rules: nothing else copies or cites it, and it is deleted once its work is built.

## Resuming
When pointed to a saved file, rebuild the tree from it, orient, then ask its open questions. Continue the question numbering.
