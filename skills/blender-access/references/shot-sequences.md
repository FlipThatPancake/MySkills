# Shot sequences and variants

Use when multiple cameras, shot-specific staging, or editorial timing matter.
For detailed motion authoring and render settings, use the applicable Blender
Agent Studio animation or rendering workflow when available.

- **Choose what is shared.** Keep a common baseline for scale, layout, and
  look where continuity matters. Isolate shot-specific staging, visibility,
  and timing as overrides or in a separate editable version. When a prop
  moves or hides, include its hardware and other dependent parts. Deliberate
  changes between shots belong in the shot notes.
- **Identify each shot by purpose and source.** Keep a small shot list if
  the sequence needs it. Useful fields are shot ID, purpose, scene version,
  camera, source frame range and frame rate, editorial placement, and any
  handles or effect cues. Source ranges can overlap or start over. Track
  onset and release against the shot or action so trims and retimes can be
  checked explicitly.
- **Preview the cheapest evidence for the decision.** Use a still for a
  framing change and a short animatic or representative segment for motion,
  clearance, and transitions. For an effect shared by many objects, test the
  event with a few visible elements and check continuity as they enter and
  leave the motion. Include a beat before or after the action when it helps
  the viewer read the change.

For downstream effects or editing, see [Compositing handoff](compositing-handoff.md).
