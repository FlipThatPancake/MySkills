# Realtime Materials Free

Use for quick procedural surfaces and look development. The enabled add-on's
module folder contains `material_categories.json` and
`Realtime_Materials.blend`. The JSON lists categories and exact material
names. Blend-file contents were readable through Blender MCP on 2026-11-06.
The bundle includes preview objects. Use the add-on UI for preview and
application, or choose the intended material datablock by its exact name.

| Bundled material | Use |
| --- | --- |
| `Variant Stucco` | Plaster detail for exterior walls |
| `Variant Color Paint` | Adjustable painted surfaces on props |
| `Black White Terrazzo` | High-contrast decorative floors or counters |
| `Ash Wood` | Light wood for simple furniture and interior tests |
