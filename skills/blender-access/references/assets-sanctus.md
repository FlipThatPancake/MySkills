# Sanctus Library

Use for editable procedural materials, parametric props, shader modules and
stickers. Version 3.3.2 was enabled on 2026-11-06. From the active module's
`__file__`, look under `lib/materials`, `lib/gnassets`, `lib/smodules`,
`lib/stools` or `lib/stickers` for the needed type. Filter filenames by
category or keyword and inspect just the matching blend files through MCP.
The installed library held 381 blend files across asset and utility folders.

| Verified bundle example | Use |
| --- | --- |
| `materials/Stones/marble_carrara.blend`, material `marble_carrara` | Editable marble for counters, tiles or display plinths |
| `gnassets/ropes and cables/cable_on_surface.blend`, object and node group `cable_on_surface` | Surface-following cables for equipment and sci-fi panels |
| `gnassets/effects/cloud_it.blend` (file observed) | Candidate for procedural cloud effects. Preview the preset in Sanctus before proposing it |

Use the Sanctus panel to preview and add items that need generated inputs or
setup. Keep the object, modifiers and supporting dependencies together for
Geometry Nodes assets.
