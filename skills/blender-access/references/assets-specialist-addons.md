# Specialist asset add-ons

These are installed tools with bundled assets or presets for a specific job.
Use the active module's `__file__` to locate its bundle. The following
examples were found in the user's Blender 5.2 installation on 2026-11-06.
Blender MCP could list datablocks in the sampled blend files. Use the add-on
panel when a preset needs custom setup, dependencies, placement or controls.

| Source | Asset or preset and use |
| --- | --- |
| Easy Fog 2 | `Assets/Blend/Procedural Volumes.blend` contains `Wisp`, `Smoke Wall2` and `Tornado` for atmospheric and smoke effects. A separate `VDB Volumes.blend` was present. |
| Extra Lights | `extra-lights-assets_only.blend` has `Natural`, `LED`, `Incandescent` and `Fluorescent` collections. Start with `Overcast Sun` or `Fireplace` for source-specific lighting. |
| RanTools | `Assets/BackDrops.blend` has `BackDrop_1` through `BackDrop_6` for studio backgrounds. Bundled light presets are in `Assets/Lights.blend`. |
| MESHmachine | Example Plug `003` under `assets/Plugs/Examples`. Browse Plug thumbnails for hard-surface details and use MESHmachine's placement workflow. |
| Cinepack V2 | Bundled render presets include 4K Cinescope and social portrait. Use for camera framing and output dimensions. |
| Lens Sim | `LensSimCollection` in `LensSim_Data/camera/camera.blend` is the add-on's lens rig. Use the Lens Sim panel for optical effects. |
| Colorist Pro | The 1.5 bundle has `Wet Lens`, `Vibrance` and selective color node groups for post-processing. |
| Lazy Composer 2 | Bundled `Vignette` and `Lens Distortion` groups for compositing. Use the panel to review settings. |
| SurfaceFlow | `Assets/SurfaceFlow.blend` contains `SurfaceFlow` and its simulation groups. Use the add-on workflow for effects that follow a surface. |
| Ground Modifier | `assets/SnapToGround_v1_2.blend` contains `Ground`, a node group for conforming objects to ground. |
| Lazy Decals | Installed and disabled. Its `Lazy_decal.blend` contains a decal node group and an asphalt demo. Consider it for surface decals when already enabled for the task. |

Physical Open Waters, Physical Starlight and Atmosphere, and A.N.T.Landscape
are enabled procedural tools for oceans, skies and terrain. Their controls
are a route for creating an effect or terrain. For a catalog search, choose
a provider from the [asset source index](asset-sources.md).
