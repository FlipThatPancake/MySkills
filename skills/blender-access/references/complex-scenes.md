# Complex scene planning and review

Use these decisions to shape the work around the brief. Passes can be combined
when the same preview or check serves both. For whole-scene construction, use
`$blender-agent-studio:blender-modeling-workflow` when available. It covers
composition, prototype checks, multiview review, and delivery validation.

- **Clarify what the references control.** Use a known dimension, relative
  size, or spatial relationship when scale matters. If references serve
  different roles, identify which guide layout, shape, materials, or mood.
  Resolve conflicts that would affect the result before building on them.
  Use context and judgment for details the brief leaves open.
- **Test the decisions that would be expensive to redo.** Choose the cheapest
  preview that can answer the current question. A rough layout can check
  circulation or composition. A clay preview can check silhouette and scale.
  A short clip can check framing, timing, and movement. If the look depends
  on an unproven asset or method, finish one representative piece before
  making a batch or expanding the scene. Inspect it under neutral light,
  then in the intended shot. Show the result and resolve any gap that would
  carry into the rest of the scene before scaling up.
- **Define the scope and finish of each substantial pass.** Name the scene
  elements it may change, the important properties to preserve, and the
  evidence that would make the change acceptable. For risky or long edits,
  save a usable checkpoint early and keep the last accepted version. End the
  pass when its checks are satisfied or the agreed limit is reached. If a
  limit ends the pass, report the remaining issue and saved checkpoint.
  Pause at review gates the user requests.

For a look revision, establish light direction, softness, and contrast from
the reference. Keep camera, exposure, and view transform fixed for comparison.
Change one major category at a time and preserve accepted settings outside it.
Inspect local surface and light contributions before changing global exposure.
If a focused retry leaves the same visible defect, change methods before
making more variants. For multiple looks, keep named lighting variants on
the same geometry when practical.

## Optional brief

Use only the fields that help the task. A few lines in the existing project
notes or the conversation are sufficient.

- Intended result and how it will be used
- Binding references, scale anchors, and room for interpretation
- Scope of this pass and what to preserve
- Preview or measurement that will answer the current question
- Criteria for finishing the pass and the checkpoint to retain, if needed

For optional examples, the [Kapwing dragon build](https://www.kapwing.com/resources/how-to-turn-gpt-6-astra-into-your-own-film-studio-blender-seedance-2-5/)
shows how a team separated scale, layout, and motion tests. The
[Giza revision](https://www.superbash.ai/benchmarks/gpt-6-astra/five-builds-2026-10-02/)
shows a scoped change to an existing scene with a matched comparison view.
[Brandon Lerry's bedroom project](https://brandonlerry.beehiiv.com/products/free-blender-bedroom-scene-prompts)
is a worked example of separate prop studies, a shared scene, and shot development.
