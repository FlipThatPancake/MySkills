name: wait-what
description: Use when the user says /wait-what, "I don't understand that", "what?" or otherwise shows a reply did not land.
---

The last message did not land. Re-pitch it:
- Start with one or two sentences of context: what we were doing and where it got to.
- Use ASD-STE100 Simplified Technical English: short sentences, common words, one idea per sentence.
- Use the terms from the project's glossary (`knowledge/glossary.md`) if it has one; otherwise the words the user uses. Define any other technical word the first time it appears.
- End with the one thing the user needs to decide or know.
- Keep replies at this level for the rest of the session.
