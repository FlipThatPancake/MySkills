# Scale

1 unit = 1 mm, real-world sizes, so homes built in separate projects match.
- Axes: x right, y up, z toward the viewer; floor at y 0. compose.mjs works in each area's own frame.
- Reference sizes (mm): ceiling 2500–2700; door 2100 × 800; window sill 900–1000; worktop top 900, depth 600; wall units from 1450, depth 320; table top 740–750; chair seat 450; sofa seat 420, depth 900; bed top 500; standing eye height 1600.
- Lens: home view 30°; shots 26–40°.
