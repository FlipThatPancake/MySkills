# One-time setup

This directory is disposable. Work on the project-local copy; preserve the reusable download and shared skill installations.

1. Merge the pack's root `AGENTS.md` and `.claude/skills/` with project files, reviewing differences first. For Claude Code, use the generated Claude edition instead; it supplies `.claude/skills/` and a `CLAUDE.md` that imports `AGENTS.md`. Merge a supplied `CLAUDE.md` import with existing Claude instructions rather than overwriting them. Keep one canonical skill set. Follow save-changes for proposed writes, including cleanup. Its publishing step follows the project's workflow, or commits and pushes to the current branch when none is defined. Grill-me's optional glossary or domain-modeling skill is not bundled.
2. Preserve an established knowledge system. For a new one, copy `starter/` tools, tests, and knowledge into matching project paths without printing code/test bodies. Merge missing reading guidance from its `AGENTS.md`, replace the illustrative brief, and use the maintenance skill to organize supplied material. The audit collector is installed but inactive unless requested. Python 3 needs no external packages.
3. Check copied tool/test bytes locally. Run `python3 tools/context.py validate` and `python3 -m unittest discover -s tests`, or the existing system's equivalents. Verify source preservation, a narrow read, and a batched comparison. Fix introduced failures and rerun affected checks. Keep this directory if setup is incomplete or checks fail; report unresolved failures.
4. After success, delete only this pack's project-local `bootstrap/` directory and remove the entire **One-time knowledge setup** section from root `AGENTS.md`. Remove any other setup-only pointers introduced by this installation. Keep project knowledge, installed tools/tests, skills, ongoing reading instructions, and any root `CLAUDE.md` adapter. Never delete user-authored additions or shared resources as cleanup.
5. Check remaining local instruction links, run a targeted read without bootstrap present, and confirm the installed knowledge skill has no starter dependency. Review scoped edits and copy checks; avoid full diffs of copied tooling.

For an already initialized project, verify its existing system before discarding unused bootstrap files. Cleanup happens once after successful initialization, not at every session.
